# Guardiana — lista "entrega": nombres que son la carretera, no el destino.
#
# Una red de entrega (CDN) reparte el contenido de otras empresas. Cuando un
# aparato pide `e673.dsce9.akamaiedge.net`, no está hablando con Akamai como
# servicio: está recogiendo lo que otro le sirve a través de Akamai. Ponerlo
# junto a los demás nombres, sin decirlo, hacía que una consulta de reparto
# pareciera un destino más.
#
# Solo entran sufijos que **únicamente** se usan para repartir. Por eso no está
# `amazon.com` (es una tienda) aunque sí `cloudfront.net`, ni `google.com`
# aunque sí `gvt1.com`. Cada sección @ es la red; cada línea, un sufijo suyo.
# Fuente: la documentación pública de cada red y los propios nombres servidos.
# Como la lista de empresas: dice quién reparte, nunca qué hace (decisión 61).
