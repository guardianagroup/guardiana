# Las letras que van dentro

Aquí están las tipografías que usa GUARDIANA, servidas desde el propio equipo para que ni el
panel ni la web pidan nada a ningún otro dominio (decisión 38). Se redistribuyen con su licencia,
que es lo que la licencia pide:

| Familia | Autor | Licencia |
|---|---|---|
| IBM Plex Sans, IBM Plex Mono | IBM Corp., 2017 | SIL Open Font License 1.1 — [OFL-IBM-Plex.txt](OFL-IBM-Plex.txt) |
| Unbounded | The Unbounded Project Authors, 2022 | SIL Open Font License 1.1 — [OFL-Unbounded.txt](OFL-Unbounded.txt) |

Los archivos `.woff2` son los subconjuntos latinos, recortados para que pesen poco. No se han
modificado los dibujos de las letras ni se ha cambiado el nombre de ninguna familia.
