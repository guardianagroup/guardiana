# Guardiana — «Haz que te borren» (decisión 204): empresas conocidas que compran, venden o
# reúnen datos personales, con el canal que ELLAS publican para pedir que te borren.
#
# Qué es y qué no es. Esta lista sirve para escribir una carta y para decir qué nombres de cada
# empresa pidió la casa. Nunca dice que una empresa «tiene tus datos»: eso solo lo sabe ella, y
# la carta es justamente la manera de preguntárselo. Las direcciones y los formularios son los que
# la propia empresa publica; ninguno se ha inventado ni deducido. Si no se pudo comprobar un
# correo, no hay correo: la carta se copia y se pega en su formulario.
#
# Fuentes, en este orden:
#   1. La página de privacidad de la propia empresa, abierta el 11 de octubre de 2026.
#   2. Para las inscritas en California, la página de derechos que ellas mismas declararon en el
#      registro de corredores de datos de la CPPA (https://cppa.ca.gov/data_broker_registry/),
#      según la copia del 8 de octubre de 2026 que ya usa crates/lists/data/corredores.txt.
# Cada sección lleva sus `fuente` con la fecha en que se miró.
#
# FORMATO
#   @id|Nombre|XX|tipo     id en minúsculas (lo usa el panel y el reloj); XX país ISO de la
#                          sociedad que lleva ese servicio y contesta la carta (Equifax Ibérica es
#                          ES aunque el grupo sea de EE. UU.), vacío si no se comprobó; tipo:
#                          personas (buscador de personas), datos (corredor de datos),
#                          publicidad, credito
#   url URL                la página o el formulario oficial para pedir el borrado o la baja
#   correo DIRECCION AMB   un correo publicado por la empresa para estos derechos; AMB son las
#                          jurisdicciones (códigos del panel, separados por comas) para las que
#                          la empresa lo da, o * para todas
#   estado cerrado|incautado   la empresa cerró ese negocio, o la web ya no es suya (con fuente)
#   fuente URL AAAA-MM-DD  de dónde sale lo de arriba y cuándo se miró
#   dominio                un nombre (coincide con él y con sus subdominios)
#   =Empresa               todos los nombres de esa sección de crates/lists/data/empresas.txt
