# Certificados de prueba del relé

Solo para la prueba `rele::tests` de este crate: una autoridad inventada (`ca.pem`) y un certificado para el nombre `rele.prueba` firmado por ella (`fullchain.pem`, `privkey.pem`). No sirven para nada fuera de esa prueba: ningún equipo confía en esa autoridad. Su clave privada se tiró al generarla.
