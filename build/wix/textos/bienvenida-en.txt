GUARDIANA for Windows

GUARDIANA brings together the ZERO browser, which cuts tracking attempts in real time and shows you every advertising auction; monitoring of the whole computer, which shows which companies your PC connects to; and the Watch, which pauses your GUARDIANA calls if another program uses your microphone, camera or screen (turn it on in Communications › Settings). Everything happens on this PC: no account and no telemetry.

What this installer will do
- Copy the program to “Program Files\Guardiana” and the GUARDIANA ZERO browser to “Program Files\Guardiana\ZERO”. ZERO uses Microsoft Edge WebView2, which already comes with Windows.
- Register the “GUARDIANA” service, which starts with Windows.
- Add the “Guardiana” shortcut, which opens the panel, to the Start menu and the desktop.
- Make GUARDIANA this PC's DNS, over IPv6 too. It first keeps an exact copy of your setting; uninstalling leaves it exactly as it was.
- Create the Windows task “GUARDIANA\Vigilante”, which checks every minute that GUARDIANA answers and, if it does not, gives the previous DNS back, so the PC is never left without internet.
- Add the program folder to the PATH, so “guardiana verify” works in any console, and register guardiana:// links to activate the licence from the email.

What it will NOT do
- It does not read the content of what you send or receive: only the name of the service, the time and the device.
- It does not open any port to the network. Only Home Mode, when you turn it on, opens ports on the home Wi-Fi; turning it off closes them.

After installing
When it finishes, the panel opens and within a minute you will see this PC's queries. To give the DNS back without uninstalling: panel, “Status”.

Seven days with everything and no card. After that GUARDIANA keeps working for free, with the history of the last 24 hours; the VPN, Home Mode and the full history come with the Plus subscription.
