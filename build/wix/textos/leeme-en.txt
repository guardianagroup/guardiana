GUARDIANA for Windows
=====================

GUARDIANA brings together the ZERO browser, which cuts tracking attempts in
real time and shows you every advertising auction; monitoring of the whole
computer, which shows which companies it connects to; and the Watch, which
pauses your GUARDIANA calls if another program uses your microphone, camera or
screen. Everything happens on this computer: no account and no telemetry.

What the installer did
----------------------
- Copied the program to “Program Files\Guardiana”.
- Registered the “GUARDIANA” service, which starts with Windows.
- Copied the GUARDIANA ZERO browser to “Program Files\Guardiana\ZERO”.
- Added the “Guardiana” shortcut, which opens the panel, to the Start menu and
  the desktop.
- Made GUARDIANA this computer's DNS, over IPv6 too, with an exact copy of the
  previous setting. If the service stops, the computer gets its previous DNS
  back; uninstalling leaves it exactly as it was.
- Created the Windows task “GUARDIANA\Vigilante” (in “Program Files\GUARDIANA
  Vigilante”): every minute it checks that GUARDIANA answers and, if it does not,
  gives the previous DNS back, so the computer is never left without internet.
- Added the program folder to the PATH and registered guardiana:// links
  (to activate the licence from the email).
- It opened no port to the network. Only Home Mode, when you turn it on, opens
  ports on your home Wi-Fi; turning it off closes them.

After installing
----------------
Start menu > Guardiana. The panel opens and you will see this computer's
queries from the first minute. To put the DNS back as it was without
uninstalling: panel, “Status”. Blocking one specific name works
from the first minute; broad blocks, by category or for the whole home, wait until
GUARDIANA has been watching that device for 24 hours.

It is seven days with every feature, Home Mode included, no card needed. After that
GUARDIANA keeps working for free, with the history of the last 24 hours; the VPN,
Home Mode and the full history come with the Plus subscription. What was written
down stays on your disk, whether you pay or not.

Uninstalling
------------
Settings > Apps > GUARDIANA > Uninstall. On uninstall, GUARDIANA turns Home
Mode off, removes its firewall rule and puts the DNS back as it was. The
ledger stays in C:\ProgramData\Guardiana; delete it by hand if you do not
want it.

Checking the installation
-------------------------
In a new command window or PowerShell:
    guardiana verify

Before installing: check the hash of the .msi file and compare it with
SHA256SUMS and with the public record (ledger.jsonl). How to do it, step by
step, is in VERIFY.md, in the published source code (github.com/guardianagroup/guardiana).

What GUARDIANA does not do is in WHAT_IT_DOES_NOT_DO.md. Read it.
